# ODC Market desktop app — installers

Windows installers for the ODC Market (IDNUK) desktop app. No source code lives here.

- **New install:** open the [latest release](https://github.com/smandco-odc/odc-desktop-releases/releases/latest), download `IDNUK-Setup-<version>.exe` and run it. Windows SmartScreen says "Unknown publisher" — click **More info → Run anyway**.
- **Updates:** installed apps (0.1.2 and later) check this repo and update themselves — or use **File → Check for Updates…**.
